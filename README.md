# RPG Demo — HKU Orientation

A shared RPG demo repository created for university orientation activities, allowing new students to explore the University of Hong Kong through an interactive experience.

## Overview

This project was made available to new students as an interactive way to explore HKU and become more familiar with the university environment.

## My Involvement

I helped make the shared repository available for new students to explore.

I was not responsible for the game's programming or original development.

## Project Purpose

To provide incoming students with an interactive experience for exploring HKU.

## Project Type

Shared university orientation project.
